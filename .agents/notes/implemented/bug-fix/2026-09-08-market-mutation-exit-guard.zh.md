# Agent Note: 插件市场修改期间的退出保护

Status: implemented

[English](2026-09-08-market-mutation-exit-guard.md) | 中文

## Problem

插件市场 CLI 操作可能比 Harness 存活更久。卸载期间退出可能留下仍存活的持锁进程，此时依赖已移除但 Bundle 协调尚未完成。下次启动进入安全模式，而不是读取仍在变化的 Profile。

## Decision

桌面的共享忙碌判断包含只读 Profile 修改锁检查，不仅检查快照和演练状态。恢复预览和恢复退出在报告成功前拒绝忙碌请求；生命周期退出和重启再次检查同一条件。就绪后的快照调度也会等待持锁操作完成。

## Alternatives considered

删除活动锁会允许多个写入者竞争。仅定时终止 pnpm 可能让生命周期脚本的后代进程在 CLI 释放锁后继续写入。退出流程不采用这两种捷径。

## Consequences

正常完成后释放锁并允许退出。所有者记录损坏或无法读取时采取失败关闭。孤立进程需要明确诊断和恢复；此保护不限制 pnpm 执行时间，也不保证外部强制终止后的进程树清理。回归测试结合真实锁文件与生命周期控制器，并检查生产 IPC 接线。原生 Windows 和 Linux 进程终止仍未验证。
