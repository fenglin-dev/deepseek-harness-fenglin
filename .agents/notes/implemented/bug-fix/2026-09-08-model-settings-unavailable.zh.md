# Agent Note：提供方设置不可用

Status: implemented

[English](2026-09-08-model-settings-unavailable.md) | 中文

## 问题

提供方目录可能先注册，而其设置分区随后拒绝缺少显式协议的旧模型配置。模型页因此存在可选目录项，却没有编辑器所需的结构。可点击的新增操作不显示内容，表现类似导入的凭据丢失。

## 决策

模型页从既有目录与设置快照推导不可用分区。页面在无障碍警告中列出这些分区，提供只读重试，并从新增列表排除不可用提供方。健康提供方的编辑器保持可用。恢复说明要求备份设置、修正配置并重启 Harness；页面不猜测协议，也不删除凭据。

## 考虑过的替代方案

自动指定协议可能错误路由请求。拒绝整个页面又会隐藏独立的健康提供方。此警告保留 Host 的严格校验，不引入第二套配置存储。

## 后果

组件测试覆盖分区缺失、新增禁用、健康提供方访问、只读重试，以及设置镜像刷新后的编辑器恢复。警告标明分区而不是 Host 异常；具体原因仍需查看启动诊断。本次修改不使无效配置变为可加载，也不验证远端模型可用性。
