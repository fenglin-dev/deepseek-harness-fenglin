# Agent Note: 社区配置目录身份识别

Status: implemented

[English](2026-09-15-community-data-home-identity.md) | 中文

## Problem

首次启动选择页原先会把任何包含可识别 DSH 文件的目录当作可复用的社区桌面数据。其他桌面发行版也可能使用这些通用文件，但携带不兼容的 Profile、插件或桌面状态。直接复用官方数据还会让桌面端专用变更影响官方环境。

## Decision

首次启动选择页只允许导入官方 DeepSeek Harness 数据。社区数据只有在主进程验证 Harness home 中存在本发行版的 `.open-deepseek-harness-desktop.json` 身份文件，或存在指向该 home 的有效旧版 `data-home-setup.json` 记录后，才能直接复用。本应用创建、复制、导入或采用 home 时会原子写入身份文件。

来源选择使用原生目录选择器签发的不透明记录，最终确认会重新验证声明的来源类别和身份。仅含通用 DSH 内容的目录、损坏的身份文件、其他发行版的身份 schema 以及无效旧版设置记录都会被拒绝。已有设置中直接复用官方 home 的记录仍可兼容读取，但选择页和渲染进程协议无法再创建这种记录。

## Alternatives considered

**继续识别通用 DSH 文件。** 这种方式兼容范围较大，但无法区分本应用与其他社区桌面发行版。

**复制所有选中的目录。** 这种方式避免直接共享，却会无谓复制已经验证的社区桌面 home，并移除用户明确选择复用的流程。

## Consequences

官方导入不会修改来源目录。社区复制和直接复用只接受已确认属于本发行版，或由本发行版旧设置记录覆盖的数据。既没有身份文件、也没有旧设置记录的历史社区 home，需要先由能够记录身份的兼容版本打开，或通过受支持的迁移流程导入；手工添加 marker 不代表兼容性保证。
