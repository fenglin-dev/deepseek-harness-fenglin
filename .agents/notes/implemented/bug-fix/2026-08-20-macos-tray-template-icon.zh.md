# Agent Note: 为 macOS 托盘提供专用模板图标

Status: implemented

[English](2026-08-20-macos-tray-template-icon.md) | 中文

## 问题

桌面宿主把完整的 1024 像素应用图标缩小后标记为 macOS 模板图。由于圆角方形背景并不透明，macOS 会把整个方块转换成单一的菜单栏颜色，最终显示成纯白按钮，而不是应用标志。

## 决策

macOS 默认使用根据[确认版透明原图](../../../../apps/desktop/assets/tray-icon/approved-white-transparent.png)生成的白色加透明通道 `tray-iconTemplate.png`。[黑白确认图](../../../../apps/desktop/assets/tray-icon/approved-black-on-white.png)保存在同一目录。人物、鲸鱼、眼睛与向外凸出的下颌轮廓保留确认版几何，嘴部及图形之间的空隙保持透明。透明通道边界 `(167, 366, 1012, 576)` 只移除外围空白。按比例适配到 28×16 区域，再添加一像素透明边距，得到横向的 30×18 图片；Retina 资源将所有尺寸翻倍。模板模式让 macOS 根据菜单栏为透明轮廓着色，不受源像素为白色的限制。Windows 和 Linux 默认使用完整的彩色应用图标。

## 考虑过的替代方案

**继续缩放完整应用图标。** 不透明的圆角方块会变成实心模板轮廓，无法在菜单栏形成可辨识的标志。

**将完整正方形确认图缩进菜单栏。** 外围空白会让标志过小。只裁掉这些空白即可保留确认版图形，无需重画或挤压横向比例。

## 验证

桌面资源构建会复制两个密度的模板 PNG，且不会改名。基础资源为 30×18 RGBA、72 dpi；Retina 资源为 60×36 RGBA、144 dpi。原生图标冒烟测试检查保留的人物、空心嘴部和下颌轮廓、透明边距、白色源像素、加载的两个缩放倍率，以及源资源与构建资源的字节一致性。桌面类型检查与桌面构建验证消费路径。

## 后果

默认菜单栏图标会适配系统明暗外观，并在原生状态栏尺寸下保持可辨识。[自定义桌面图标](../feature/2026-09-02-custom-desktop-icons.zh.md) 可以覆盖运行中的 Dock、窗口与托盘；自定义托盘图片保留原色而不转换为模板。系统通知与安装器继续使用内置彩色图标。
