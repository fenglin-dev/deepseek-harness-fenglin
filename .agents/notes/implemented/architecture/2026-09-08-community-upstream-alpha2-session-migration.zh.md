# Agent Note: 社区桌面版整合上游 0.1.3-alpha.2

Status: implemented

[English](2026-09-08-community-upstream-alpha2-session-migration.md) | 中文

## 问题

上游使用 SessionHandle 所有权和相邻会话格式迁移替换旧持久化协调器。保留旧协调器会形成两个持久化权威；不做适配就删除，则会拒绝可恢复的社区桌面版会话。

## 决策

整合固定到 `dsh-v0.1.3-alpha.2`（`82a5fd61a7cf5c293cec4bdff68f455398d685e9`），而非上游 master。桌面品牌、预置插件版本、原生标题栏与内容隔离、诊断恢复、快照及外部工具控制继续由下游维护。

v0-to-v1 和直接解码的 v1-to-v2 迁移阶段会暂存空标识的助手工具消息及其相邻失败调用和结果。只有轮次、步骤、参数、来源序号一致的 `UNKNOWN_TOOL` 结果才获得确定性的合成标识。存在歧义或不完整的组合会使迁移失败，不会静默丢弃事件。按代际写入的迁移器不改动旧源文件；新生成的 v2 文件保存修复后的标识。

已发布载荷清单同时纳入社区桌面版的 `external-tools/resolved` 审计事件，校验其轮次、步骤以及 Codex/Claude Code 工具名。这是有明确名称的历史扩展，不代表允许迁移任意未知事件。

CLI 启动保留依赖修复和安全模式配置组合，并在插件加载前安装上游环境代理。配置组合失败时，先释放代理，再进入桌面恢复重试。插件命令完成后继续让 Node 正常清理退出，而非强制终止进程。

## 考虑过的替代方案

内置外部工具清单与 Web 安装回退将两个官方 Provider 固定为 `0.1.3-alpha.2`，并使用经注册表验证的 SHA-512。Codex `0.149.1` 和 Claude Agent SDK `0.3.241` 保持不变。修改本地固定版本不会发布远程签名清单，也不会更新用户已经安装的工具。远程发布需针对其服务的桌面版本线另行审核兼容性。

**保留旧协调器。** 不采用：上游 SessionHandle 与独占写入租约已经拥有持久化职责，重复实现会破坏锁和迁移的边界。

**拒绝所有旧空工具标识。** 不采用：完整相邻的失败序列提供了足够证据，可以在不执行工具的情况下保留会话。

**修复任意损坏记录或跳过未知事件。** 不采用：这可能改变工具关系或静默丢失可恢复内容。严格识别的失败记录仍与成功工具执行区分。

## 影响

升级会话使用 v2 存储，不能假定旧桌面版可以读取。插件快照恢复部署状态，不恢复会话数据。验证只使用合成临时会话，不使用用户真实配置。上游进程清理改动并不能证明 Windows 工作区外删除问题已经受到防护。

已有的[网关标识决策](../bug-fix/2026-08-17-empty-gateway-tool-call-identity.zh.md)继续保留：它防止新流式响应产生错误标识，本次迁移则处理已经持久化的失败记录。

## 验证

定向测试覆盖确定性标识恢复、源记录不变、v0/v1 迁移和 v2 重新打开、历史外部工具审计事件，以及拒绝不完整或不相关工具结果。存储测试覆盖租约竞争与恢复。Windows/Linux 交互验证和第三方插件兼容性仍需单独作为发布检查，不能用 macOS 测试替代其结果。
